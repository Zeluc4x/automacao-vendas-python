# 🚀 Automação de Sistemas e Processos com Python

Este projeto é uma automação de tarefas repetitivas desenvolvida em Python. O script simula interações de mouse e teclado para acessar o Google Drive, baixar uma base de dados de vendas diárias, processar as informações usando manipulação de dados e enviar um relatório automatizado por e-mail para a diretoria.

---

## 📌 Contexto do Desafio

Todos os dias, o sistema atualiza as vendas do dia anterior. O objetivo desta automação é:
1. Acessar o link do Google Drive onde a planilha de vendas está hospedada.
2. Baixar a base de dados de vendas mais recente.
3. Calcular o **faturamento total** e a **quantidade de produtos vendidos**.
4. Enviar um e-mail formatado via Gmail contendo os indicadores extraídos diretamente para a diretoria.

---

## 🛠️ Tecnologias e Bibliotecas Utilizadas

As seguintes ferramentas e bibliotecas foram utilizadas no projeto:

* **Python 3.x**
* **PyAutoGUI** (Automação de comandos do mouse e teclado)
* **Pandas** (Análise e manipulação de dados)
* **Openpyxl** (Leitura e manipulação de arquivos Excel)
* **Pyperclip** (Manipulação da área de transferência para colar textos com acentuação)
